# Кошелёк WATA

## Балансы и история

- `wata_wallet_balances` — счета и остатки по валютам. Возьмите отсюда `accountId`,
  он нужен для истории операций
- `wata_wallet_operations` — операции по счёту за период
- `wata_wallet_rates` — текущие курсы конвертации

Учитывайте `decimals` валюты: у USDT шесть знаков, и округление «на глаз» даёт расхождения.

## Вывод средств — три шага, и порядок обязателен

```
1. wata_wallet_withdrawal_commission  → возвращает orderId и quoteId
2. wata_wallet_withdraw_initiate      → возвращает credentialTokenId (деньги ещё на месте)
3. wata_wallet_withdraw_confirm       → ДЕНЬГИ УХОДЯТ, необратимо
```

Пропустить первый шаг нельзя: `orderId` и `quoteId` рождаются именно там, и заявку
без них не создать.

**Никогда не вызывайте третий шаг без явного указания человека.** Разделение на шаги
существует ровно для того, чтобы необратимая операция не происходила по инерции.

### СБП

Нужны `bankNumber` из `wata_wallet_banks` и телефон получателя — 11 цифр, начиная с 7,
без маски и разделителей.

### Криптовалюта

Обычно USDT в сети Tron. Передаются сумма, валюта, сеть, комиссия из расчёта и адрес
получателя. Адрес проверяйте особенно внимательно: перевод в блокчейне не отменить.

### Вывод на карту

Через API **недоступен**: номер карты вводится только в защищённом виджете кабинета.
Если нужен вывод на карту — это ручная операция человека в интерфейсе.

### Подтверждение

`wata_wallet_withdraw_confirm` принимает код и `credentialTokenId` из заявки.
Для фиата дополнительно нужен `orderId`, для крипты — нет. Это не опечатка,
а разница в API.

## Лимиты и комиссии

`wata_wallet_withdrawal_limits` требует параметров, иначе сервер отвечает
«Ваш запрос недействителен»:

- фиат: `currency` (RUB) и `method` (SBP или Card)
- крипта: `currency` (USDT) и `blockchainType` (Tron)

Возвращает минимальную сумму, максимум на операцию и остаток дневного лимита.
`wata_wallet_withdrawal_commission` считает комиссию, ничего не создавая — используйте
его, чтобы показать человеку итоговую сумму до подтверждения.

## Автосеттлмент

Автоматический вывод выручки. Настройка тоже двухшаговая: `initiate`, затем `confirm`.

- `balancePercentage` — какая доля баланса выводится
- `minimumThreshold` — порог, ниже которого вывод не запускается

Текущие правила — `wata_wallet_autosettlement_get`.

## Переводы

`wata_wallet_transfer` перемещает средства между счетами кошелька: нужны сумма, валюта,
счёт списания и счёт зачисления (идентификаторы из `wata_wallet_balances`).
Это тоже денежная операция, пусть и внутренняя.

## Журнал

Все изменяющие вызовы записываются в `~/.wata-mcp/audit.log` — если что-то пошло не так,
восстановить последовательность действий можно оттуда.
